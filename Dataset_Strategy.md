## 🤖 SOURCE 2 — Project-Generated Synthetic Images

**These are images WE CREATE during the project using AI image generation.**

### Why We Create Our Own Images

| Reason | Explanation |
|--------|-------------|
| **Gap filling** | No public dataset has pharma warehouse *packing station* images specifically |
| **Defect control** | We control exactly what defect appears and where |
| **Ethics** | No real operators, no real patients, no real product names |
| **Cost** | Free — generated by the project's own AI tools |
| **Pharma-specific** | Temperature zone packaging, cold chain bags — not in general datasets |

### What We Generate (7 Categories, ~950 images total)

```
CATEGORY          | COUNT | DEFECT DESCRIPTION
──────────────────|──────|─────────────────────────────────────────
CORRECT_PACK      |  200 | Properly sealed, labelled, padded — dispatch ready
CRUSHED_BOX       |  150 | Structural box damage (corner/side/top crush)
BROKEN_SEAL       |  150 | Blister or box seal failed/open
WRONG_CONTAINER   |  150 | Item in wrong packaging type or size
MISSING_LABEL     |  100 | No label, partial label, barcode obscured
INSUFFICIENT_PAD  |  100 | Inadequate cushioning for item fragility class
TEMP_BREACH_PACK  |  100 | Cold chain packaging failure (no ice pack, wrong bag)
──────────────────|──────|─────────────────────────────────────────
TOTAL             |  950 |
```

## 🔄 SOURCE 3 — Data Augmentation

Taking Source 1 real images and creating 5× more variants:

```python
import albumentations as A

augment = A.Compose([
    A.RandomRotate90(p=0.5),
    A.HorizontalFlip(p=0.5),
    A.RandomBrightnessContrast(brightness_limit=0.3, p=0.7),
    A.GaussianBlur(blur_limit=3, p=0.3),
    A.RandomShadow(p=0.2),
    A.Perspective(scale=(0.05, 0.1), p=0.4),
    A.CoarseDropout(max_holes=4, max_height=30, max_width=30, p=0.2),
])
# 13,000 real images → ~65,000 augmented images
```
